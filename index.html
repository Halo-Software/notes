About:

"It is simple. That's not all."

Notes by Halo is a comfortable and simple note-taking application, featuring the following main features.

  • Colour Tags

    Managing memos by colour makes them intuitive to handle.

    - Some people like to organise.

  • Sync*

    Notes by Halo offers the possibility of synchronising notes using QR codes as well as the more common internet-based method.

    - Sync is power.
Features with * are under development.

  • For macOS (Homebrew)

    Install via Homebrew (Apple Silicon):

    brew tap halo-software/tap
brew install --cask notes-by-halo

    Normally, the app opens directly after installation without security prompts. (If macOS displays a warning on launch, go to System Settings → Privacy & Security and click Open Anyway.)
