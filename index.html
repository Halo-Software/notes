How to Get?

Windows

Available for Windows 10 and Windows 11 devices via the official Microsoft Store.

Android

Available for Android smartphones and tablets on Google Play.

macOS (Homebrew)

Install via Homebrew for Apple Silicon Macs: 

brew tap halo-software/tap
brew install --cask notes-by-halo
Direct launch supported. No security prompts on modern macOS.
