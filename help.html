Help & Guides

Direct Cloud Synchronization

Notes by Halo keeps your notes purely client-side without vendor lock-in. You can synchronize your markdown notes across your devices using your own private storage:

  • WebDAV: Synology NAS, Nextcloud, QNAP, ownCloud, or custom HTTPS WebDAV servers.
  • Google Drive: Direct sync to your personal Google Drive account using the restricted, non-sensitive drive.file scope.

WebDAV Setup Guide (Synology NAS & Nextcloud)

To protect your credentials, always connect over HTTPS and use a dedicated user account or app password limited to your notes directory.

1. Synology NAS (DSM) Setup

  1. Log into Synology DSM as an administrator.
  2. Open Control Panel > Shared Folder and create a shared folder named NotesByHalo.
  3. Open Control Panel > User & Group and create a dedicated user (e.g. halonotes_sync).
  4. Under Permissions, grant Read/Write only to NotesByHalo, and set all other folders to No Access.
  5. Under Applications, ensure access to WebDAV Server is set to Allow.
  6. Open DSM WebDAV Server package, check Enable HTTPS (default port: 5006).
  7. In Notes by Halo Settings (About), enter your WebDAV URL: https://<your-nas-host>:5006/NotesByHalo, username, and password, then click Test Connection.

2. Nextcloud Setup

  1. Log into Nextcloud, click your avatar > Personal settings > Security.
  2. Under Devices & client credentials, type Notes by Halo and click Create new app password.
  3. Copy the generated app password.
  4. In Notes by Halo Settings, enter your Nextcloud WebDAV URL: https://<your-domain>/remote.php/dav/files/<username>/NotesByHalo, your username, and the generated app password.

Google Drive Direct Sync (OAuth 2.0 PKCE)

Notes by Halo connects directly from your device to Google Drive via RFC 7636 PKCE. It uses the non-sensitive https://www.googleapis.com/auth/drive.file scope, meaning the app only accesses files and folders it creates (under /NotesByHalo/).

1. Creating an OAuth 2.0 Client ID (Free)

  1. Open Google Cloud Console and create a new project (e.g. My HaloNotes Sync).
  2. Navigate to APIs & Services > Library, search for Google Drive API, and click Enable.
  3. Navigate to APIs & Services > OAuth consent screen:
    • Select External and click Create.
    • Fill in App name (Notes by Halo) and your email address.
    • In the Scopes step, add .../auth/drive.file.
    • In the Test users step, add your own Google account email address.
  4. Navigate to APIs & Services > Credentials > Create Credentials > OAuth client ID:
    • Application type: Web application.
    • Name: Notes by Halo Web Client.
    • Authorized redirect URIs: Add both https://notes.gethalo.software/about.html (for Web / PWA) and http://127.0.0.1:8080/about.html (for PC / Electron).
  5. Copy your generated Client ID (format: 1234567890-xxx.apps.googleusercontent.com).

2. Signing In from Desktop (PC / Electron)

  1. Paste your Client ID into the Settings (About) screen in Notes by Halo.
  2. Click Sign in with Google. A browser window will open asking for your Google account consent.
  3. After authorising in the browser, copy the authorization code (or the full redirect URL from the address bar) and paste it into the Authorization Code input in the app.
  4. Click Complete Login. The app will securely exchange tokens and begin sync.

3. Importing Existing Markdown Files via Google Picker

Because the app strictly uses the drive.file scope for your privacy, it cannot see external files placed in your Drive by other tools by default.

To import existing markdown notes into Notes by Halo, click Import from Drive in the Google Drive settings card. Select your .md or .txt files in the official Google file picker dialog to grant access and import them immediately into your local notes collection.
