About

「シンプル。それだけじゃない。」

個別のMarkdownファイル保存、BYOSクラウド同期、AI・MCP連携を備えた快適でミニマルなメモ帳アプリです。

  • カラータグ

    メモを色ごとに管理することで、直感的な分類とリアルタイムな色絞り込みが可能です。

    - 整理好きな人っているよね。
Features

同期とAI連携

  • BYOS クラウド同期

    メモは透明性の高いMarkdown（.md）ファイル保存。OneDriveやDropbox、iCloud等の同期フォルダを自由に選べます。

    - 自分のストレージは自分で選ぶ。

  • AI & MCP 連携

    Model Context Protocol（MCP）を標準搭載。ClaudeやCursorからメモの全文検索・編集・タスク抽出が直接行えます。

    - AIと個人の知見をつなぐ。

How to Get?

Windows 版

Windows 10 および Windows 11 向けに Microsoft Store で配信しています。

Android 版

Android スマートフォン・タブレット向けに Google Play で配信しています。

macOS 版（Homebrew）

Homebrew を使ってインストール（Apple Silicon 対応）: 

brew tap halo-software/tap
brew install --cask notes-by-halo
通常はインストール後そのまま起動できます。
